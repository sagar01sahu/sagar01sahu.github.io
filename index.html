RailConnect

Railway Ticket Booking Backend API Repository ↗

Java 17 · Spring Boot 3 · Spring Security · JWT · JPA/Hibernate · MySQL · Redis

  • Stateless REST API for railway schedules and ticket booking, with JWT authentication and role-based access for ROLE_CLIENT and ROLE_ADMIN.
  • Optimistic locking via JPA @Version to stop double-booking when two requests hit the same seat at once.
  • Redis caching on train search (@Cacheable / @CacheEvict), cutting response times from ~50ms to ~2ms.
  • Normalized MySQL schema and layered REST endpoints for registration, login, search, booking, and admin train management.

Microservices Backend for Farm Equipment Rental Repository ↗

CyberGuard AI

Microservice Anomaly Detection Backend Repository ↗

Java 17 · Spring Boot · PostgreSQL / H2 · JWT · Microservices · REST APIs

  • Built the Spring Boot orchestration layer that ingests enterprise access logs through a secured X-API-Key endpoint and persists state in PostgreSQL/H2.
  • Dual authentication design — ApiKeyAuthFilter for machine-to-machine log ingestion, JwtAuthenticationFilter for dashboard access.
  • LogProcessingService pulls historical context per entity, calls a separate AI microservice for a risk score, and raises alerts above a 0.85 threshold with retry/fallback handling.
  • REST endpoints for live alerts, dashboard stats, and telemetry, integrating with an external FastAPI + PyTorch Geometric scoring service over HTTP.

LastMile Pro

Last-Mile Delivery Management Backend Repository ↗

Java 21 · Spring Boot 3.3 · Spring Security (JWT) · PostgreSQL 16 · Spring Mail

  • Modular-monolith backend for a multi-tenant delivery platform, with dynamic zone detection and dimensional pricing.
